Adaptive Speed Focus (aSFM) — an auto-REVEAL timer that never grades

After the question shows, aSFM waits a delay computed from the card's length and
FSRS difficulty, then reveals the answer automatically. It NEVER grades the card
for you — you still press the button yourself.

WHAT IT DOES
• Waits (base + per-word × words) × familiarity × difficulty, clamped between a
  minimum and maximum, then auto-reveals.
• Counts only the text you actually SEE — hidden fields and AnKing-style tag chips
  don't inflate the timer.
• Gives new and learning/relearning cards more time (tunable).
• Nudges the delay by the card's FSRS difficulty — harder cards get longer,
  bounded so it's only a gentle shift.
• Optional thin countdown bar and a warning sound before the reveal.
• A "More time" button on the card, and a pause key (default P) — either one holds
  the countdown where it stands so you can sit on a card, and picks it up where it
  stopped. The hold sticks across cards and every card it applies to says so on
  screen. The button stays faint until you hover it.
• Picture-card mode: chosen note types / decks use a SET time instead of a word
  count, since there's nothing to read.

BEFORE YOU START
If you run Glutanimate's Speed Focus Mode, disable it so the two timers don't
double up. If you run the full AnkiBlitz suite, this feature is already included —
don't install both.

USING IT
Tools ▸ Adaptive Speed Focus ▸ Settings… — all the knobs plus a live preview that
always matches the runtime.

CHANGES IN 1.2.0
• NEW: a visible "More time" button, by request — the same hold the pause key
  applied, but you can now see that it's there. Click it to stop the countdown,
  click it (or the "paused" badge) again to carry on. Turn it off in Settings if
  you'd rather keep the card clear.
• NEW: a pause key (default P) for the same hold, if you prefer the keyboard.
  Give it a different key from Progressive Word Reveal's if you run both.
