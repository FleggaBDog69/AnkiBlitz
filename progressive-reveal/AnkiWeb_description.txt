Progressive Word Reveal — fade the question in word by word

Fades the card's question in word by word at a reading pace you set, so longer
questions take proportionally longer to appear. Click or press the reveal key to
show everything at once.

WHAT IT DOES
• Fades words (or fixed-size chunks of words) in at a set words-per-second.
• Counts only the text you actually SEE — scripts/styles, MathJax, and CSS-hidden
  AnKing tag chips / hint chrome are skipped, so the pace tracks what you read.
• Optional TTS sync: lock the reveal to a card's native Anki / AnKing {{tts}}
  voice so the words finish in step with the audio (exact on macOS).
• Optional reveal on the answer side too.
• Revealing everything early also stops the card's audio — you've read it, so the
  voice still reading it to you is just noise. Optional.
• Per-note-type / per-deck exclusions.

BEFORE YOU START
If you run Patrick Lee's original Progressive Word Reveal, disable it so the two
don't double up. If you run the full AnkiBlitz suite, this feature is already
included — don't install both.

USING IT
Tools ▸ Progressive Word Reveal ▸ Settings… — speed, mode, chunk size, reveal
key, stop-audio-on-reveal, TTS sync, exclusions, and a live preview.
